# dsa-history

Daily DSA practice solutions, organized by `day-N/` folders.

## Submit solution(s) (fast path)

1. Open **[Submit DSA solution(s)](https://github.com/fadexadex/dsa-history/issues/new?template=dsa-submit.yml)**
2. Paste one or more solutions for the same day (separate problems with a line that is only `---`)
3. Submit — the `dsa-submit` label starts the Cursor automation
4. The agent commits cleaned file(s) into the right `day-N/` folder and comments on the issue

Setup details for the Cursor Automation: [.github/DSA_INBOX_AUTOMATION.md](.github/DSA_INBOX_AUTOMATION.md)
