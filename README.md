# dsa-history

Daily DSA practice solutions, organized by `day-N/` folders.

## Submit a solution (fast path)

1. Open **[Submit DSA solution](https://github.com/fadexadex/dsa-history/issues/new?template=dsa-submit.yml)**
2. Paste your code (formatting does not need to be perfect)
3. Submit — the `dsa-submit` label starts the Cursor automation
4. The agent commits a cleaned file into the right `day-N/` folder and comments on the issue

Setup details for the Cursor Automation: [.github/DSA_INBOX_AUTOMATION.md](.github/DSA_INBOX_AUTOMATION.md)
